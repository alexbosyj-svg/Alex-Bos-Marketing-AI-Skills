## 🇬🇧 English

### What's inside

| Skill | What it does |
|---|---|
| [`funnel-picker`](skills/funnel-picker/SKILL.md) | Interviews you briefly about your offer, buyer and resources, then tells you which funnel to build first, which backups to keep, and why the other formats don't fit. Plain language, no methodology jargon. |

### Install

**Claude (web or desktop)**
1. Click **Code → Download ZIP** on this page and unzip it.
2. Zip the `skills/funnel-picker` folder on its own (the folder name must stay `funnel-picker`).
3. In Claude, open your skills settings, choose **Upload a skill** and upload that zip.

**Claude Code**
```bash
git clone https://github.com/<owner>/Alex-Bos-Marketing-AI-Skills.git
cp -r Alex-Bos-Marketing-AI-Skills/skills/funnel-picker ~/.claude/skills/
```
Restart Claude Code.

### Use

Ask Claude something like "which funnel should I build to sell X", or call the skill directly: `/funnel-picker`.
